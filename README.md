# dogani

dogani는 옵시디언 방식으로 쓰는 데일리 노트와 일정을 바탕화면에 띄워 두는 Windows 앱입니다. 같은 사내망의 동료와 팀스페이스를 만들면 서로의 할일과 일정을 약 1초 간격으로 함께 보고 고칠 수 있습니다. 업무 현황을 공유하고 인수인계를 빠르게 하려는 목적으로 만들었습니다.

## 주요 기능

- 오늘의 할일을 바탕화면 위 작은 창에 띄워 둡니다. 체크박스를 누르면 바로 완료로 표시되고 파일에 저장됩니다.
- 달력 창에서 날짜별 진행 상황과 일정을 한눈에 봅니다. 날짜를 누르면 할일 창이 그날 노트로 바뀝니다.
- 노트는 옵시디언과 같은 라이브 프리뷰로 편집합니다. 커서가 놓인 부분만 원문 기호가 보이고 나머지는 서식대로 표시됩니다.
- 노트는 평범한 마크다운 파일로 저장되므로 옵시디언에서 그대로 열어 쓸 수 있습니다.
- 팀스페이스를 만들면 팀원 모두가 같은 노트와 일정을 실시간으로 보고 편집합니다.
- 개인 스페이스는 내 PC에만 있으며 다른 사람에게 공유되지 않습니다.
- 앱을 켤 때마다 새 버전을 확인해 자동으로 업데이트합니다.

## 설치

[dogani-setup.exe](https://github.com/nodogani/dogani/releases/latest/download/dogani-setup.exe)를 받아 실행합니다. Python은 필요 없고 관리자 권한도 묻지 않습니다. 설치가 끝나면 시작 메뉴에서 dogani를 실행합니다.

설치 파일은 처음 한 번만 받으면 됩니다. 이후에는 앱을 켤 때 새 버전을 받아 적용하며, 켜 둔 동안 나온 업데이트는 다음 실행 때 반영됩니다. 설치 파일을 다시 실행하면 기존 설치 위에 덮어 설치됩니다.

## 시작하기

처음 실행하면 노트 폴더를 고르는 창이 뜹니다. 고른 폴더 하나가 스페이스 하나가 되며, 옵시디언의 보관함과 같은 개념입니다.

dogani는 스페이스 안의 다음 파일을 읽습니다.

- 데일리 노트는 `261030 금.md` 또는 `2026-10-30.md` 형식의 이름을 가진 파일입니다.
- 일정 파일은 `2026일정.md` 또는 `일정.md` 입니다.
- 새 노트는 `스페이스/2026.10/261030 금.md` 위치에 만들어집니다.

업무 자료가 섞여 있는 폴더를 골라도 괜찮습니다. 위 형식이 아닌 파일은 읽지 않습니다. 스페이스 폴더에는 설정을 담는 `.dogani` 폴더가 생기며, 점으로 시작하는 폴더는 노트로 읽지 않습니다.

## 화면 구성

화면은 할일 창과 달력 창으로 이루어집니다. 트레이 메뉴의 할일 표시와 달력 표시로 각각 켜고 끕니다. 트레이 아이콘을 클릭할 때마다 달력만, 할일만, 둘 다, 둘 다 닫기 순으로 바뀝니다.

창 위쪽 막대를 끌어 옮기고 오른쪽 아래 모서리를 끌어 크기를 바꿉니다. 위치와 크기는 다음 실행 때도 유지됩니다. 할일 창의 위쪽 막대는 그날 할일의 진행률을 보여 줍니다.

달력 창은 날짜마다 완료한 할일과 전체 할일의 수를 표시합니다. 달력 위의 스페이스 체크로 어느 스페이스의 일정을 보일지 고릅니다. 화면을 공유할 때 개인 스페이스를 끄면 개인 일정이 달력과 할일 창에서 모두 숨겨집니다. 스페이스 칩에 마우스를 올리면 그 스페이스의 일정만 강조됩니다.

달력 칸을 우클릭하거나 여러 날을 끌어 선택하면 일정을 추가할 수 있습니다. 일정 창에서 스페이스를 여러 개 고르면 각 스페이스에 같은 일정이 함께 저장되고, 이후 수정이나 삭제도 모든 스페이스에 함께 적용됩니다. 한 스페이스에서만 지우려면 그 칩을 끄고 저장합니다. `==쉬는 날==` 로 표시한 날은 화살표로 날짜를 옮길 때 건너뜁니다.

## 편집

노트 전체가 하나의 편집기입니다. 입력을 멈추고 0.7초가 지나면 자동으로 저장되며 Ctrl+S로 바로 저장할 수도 있습니다.

- 체크박스를 클릭하면 완료와 미완료가 바뀌고 바로 저장됩니다.
- Enter를 누르면 목록과 체크박스가 이어지고, 빈 항목에서 Enter를 누르면 목록이 끝납니다.
- Tab과 Shift+Tab으로 목록의 들여쓰기를 조절합니다.
- Ctrl+Z와 Ctrl+Y로 실행을 취소하거나 다시 실행합니다.
- 링크는 클릭하면 열리고, 주소만 적힌 링크는 Ctrl+클릭으로 엽니다.
- 표를 클릭하면 원문으로 바뀌어 편집할 수 있습니다.
- 노트 밖을 클릭하거나 Esc를 누르거나 다른 창으로 전환하면 편집이 끝납니다.

옵시디언 같은 다른 편집기에서 같은 파일을 동시에 고쳐 내용이 겹치면 dogani는 덮어쓰지 않고 알림을 띄웁니다.

## 팀스페이스

팀스페이스는 팀원 중 한 사람의 PC에 있는 폴더를 사내망으로 함께 쓰는 기능입니다. 이 PC를 팀 호스트라고 부릅니다. 켜 두는 시간이 긴 PC를 호스트로 정하는 것이 좋습니다.

### 팀 만들기

1. 호스트가 될 PC에서 트레이의 팀스페이스 메뉴를 열고 이 PC를 팀 호스트로 정합니다.
2. 팀스페이스로 쓸 폴더를 고릅니다. 개인 스페이스와 겹치는 폴더는 고를 수 없습니다.
3. Windows 방화벽 알림이 뜨면 허용을 누릅니다. 허용하지 않으면 팀원이 접속할 수 없습니다.

팀스페이스는 마크다운 파일이 들어 있는 평범한 폴더이므로 폴더를 복사하는 것으로 백업할 수 있습니다.

### 팀원 초대

1. 관리자는 트레이의 팀스페이스 메뉴에서 새 팀원 초대장 만들기를 누릅니다. 호스트 주소와 초대장 코드가 복사됩니다.
2. 복사한 내용을 메신저로 초대할 사람에게 보냅니다. 초대장은 한 사람당 하나이며 15분 안에 한 번만 쓸 수 있습니다.
3. 초대받은 사람은 트레이의 팀스페이스 메뉴에서 팀 참여를 누르고 호스트 주소와 초대장 코드를 입력합니다.

한 번 참여한 PC는 다시 묻지 않습니다. 팀에서 쓰는 이름은 트레이의 내 이름이며 처음에는 PC 이름으로 정해집니다.

팀에 들어가면 트레이에서 팀스페이스 보기와 개인 스페이스 보기로 보는 스페이스를 바꿀 수 있습니다. 호스트가 꺼져 있을 때는 팀스페이스만 보이지 않고 개인 스페이스는 그대로 쓸 수 있습니다.

### 팀 관리

관리자는 호스트 PC의 트레이에서 초대장을 복사하거나 폐기하고, 팀원을 다시 초대하거나 내보내고, 팀 이름을 바꿉니다.

- 팀원이 PC를 바꾸면 관리자가 팀원 메뉴에서 그 사람을 다시 초대합니다. 새 PC에서 팀에 참여하면 이름은 그대로 유지되고 예전 PC는 로그아웃됩니다.
- 호스트의 IP가 바뀌어도 같은 사내망이라면 팀원의 dogani가 20초 안에 호스트를 다시 찾습니다. 찾지 못하면 관리자가 트레이에서 호스트 주소를 복사해 보내고, 팀원은 호스트 주소 바꾸기에 그 주소를 입력합니다. IP가 자주 바뀐다면 공유기에서 호스트 PC의 IP를 고정해 두는 것이 좋습니다.
- 호스트를 다른 PC로 옮기려면 팀스페이스 폴더와 `%APPDATA%\dogani\team\<스페이스id>.json` 파일을 새 PC로 복사한 뒤 새 PC에서 호스트를 켭니다.

## 트레이 메뉴

트레이 메뉴에서는 화면 표시, 스페이스 전환, 팀 관리 외에 다음 항목을 설정합니다.

- 바탕화면에 고정하면 Win+D를 눌러도 창이 남아 있습니다.
- 창은 항상 바탕화면에 고정됩니다. 투명도, 다크 테마, 클릭 시 깨어나기를 고를 수 있습니다.
- 트레이 메뉴의 클릭 시 깨어나기를 켜면, 다른 프로그램을 쓰는 동안 할일·달력 창이 바탕화면처럼 옅게 멈춰 있습니다. 한 번 클릭하면 두 창이 함께 깨어나고 그다음 클릭부터 동작하며, 창을 눌러도 다른 프로그램 위로 올라오지 않습니다.
- Windows 시작 시 자동으로 실행하도록 설정할 수 있습니다.

트레이 아이콘이 초록색이면 정상 동작 중이고, 회색이면 포트가 이미 사용 중이라 스페이스를 열지 못한 상태입니다.

설정은 `%APPDATA%\dogani\dogani.json` 에 저장됩니다. 환경변수 `DOGANI_HOME` 으로 위치를 바꿀 수 있습니다.

## 보안

dogani는 사내망 안에서 쓰는 것을 전제로 합니다. 외부망에서의 사용은 고려하지 않았습니다.

- 통신은 암호화하지 않은 HTTP를 씁니다. 같은 망에서 패킷을 엿보면 노트 내용과 토큰이 드러날 수 있습니다.
- 요청에 붙는 식별 키는 공개된 코드에 들어 있는 고정값입니다. 웹브라우저로 바로 여는 것을 막을 뿐 비밀번호 역할은 하지 않습니다.
- 팀 출입은 일회용 초대장과 그로부터 받은 토큰으로만 확인합니다.
- 팀스페이스는 팀원 모두가 읽고 고칠 수 있습니다.

## 개발에 참여하기

저장소를 포크해 직접 고치고 빌드할 수 있습니다. 구성, 데이터 형식, API, 배포 구조는 [SPEC.md](SPEC.md)에 정리되어 있습니다.

### 소스로 실행

Python 3.10 이상이 필요합니다.

```
app\install.bat
app\run.bat
```

`app\run.bat --dir "D:\업무" --port 8765` 처럼 스페이스 폴더와 포트를 지정할 수 있습니다. 소스로 실행할 때는 자동 업데이트를 받지 않습니다. UI 파일을 저장하면 창이 새로 고쳐지고, 파이썬 파일을 저장하면 앱이 다시 시작됩니다.

자동 시험은 `tests/` 에 있습니다. 저장소 루트에서 `python -m unittest discover -s tests -v`(서버 동기화), `node --test tests/`(노트 합치기), `python tests/e2e_ui.py`(화면 2개와 서버, 약 1분)를 실행합니다.

### 편집기 빌드

편집기는 CodeMirror 6 기반이며 소스는 `app/editor/src/main.js` 에 있습니다. 고친 뒤 `app/editor/build.bat` 을 실행하면 `app/ui/vendor/editor.js` 가 만들어집니다. 이 과정에는 Node.js가 필요합니다.

### exe 빌드

`build.bat` 을 실행하면 `dist\dogani\` 폴더에 실행 파일이 만들어집니다. 이 폴더를 통째로 복사해 `dogani.exe` 를 실행하면 됩니다. 설치 파일은 Inno Setup으로 `installer.iss` 를 컴파일해 만듭니다.

exe는 앱 코드를 담고 있지 않고 실행할 때 내려받습니다. 따라서 `app\deps.py` 에 외부 라이브러리를 추가했거나 `app\launcher.py` 를 고쳤을 때만 exe를 다시 빌드하면 됩니다.
